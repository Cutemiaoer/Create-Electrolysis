
Create: Electrolysis
=======

This addon for **Minecraft Create** add a new recipe type: **Electrolysis**, and a new kind of fuel: Hydrogen.
Connect pipes to blaze burners to use the gas.It can let the blaze burners **superheat**.

And it's easy to add new electrolysis recipes, so it's a good choice for you modpack.

REQUIRED DEPENDECIES!
============
1. Create itself
2. Minecraft (NeoForge 21.1.238+)
3. **Create: Liquid Fuels** or **Create: Diesel Generators**.(If you use other similar mods, you should add the burning recipe by yourself.)
4. Any addon that can convert SU to Fe (such as Create: Crafts and Additions)

How to use: 
==========
* Firstly, you need to make an electrolyzer.You can find the recipe of it by JEI.

* Secondly, put the electrolyzer on a basin, and inlet water to the basin.

* Thirdly, connect EF energy to the electrolyzer, and you’ll get hydrogen and oxygen in the basin.

* Finally, use smart pipes to exhaust the hydrogen and oxygen.

For modpack developers:
==========
The recipe type is **"createelectrolysis:electrolysis"**.
The format of the recipe files is the same as mixing recipes of Create.
